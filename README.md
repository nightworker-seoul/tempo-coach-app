# 템포 코치 (Tempo Coach)

이어폰으로 들으면서 하는 헬스 근력 세션 안드로이드 앱이에요. 화면을 안 봐도 음성과 효과음이
운동 이름, 템포, 휴식, 다음 기구까지 알려줍니다.

## 다운로드

**[tempo-coach.apk 받기](https://github.com/nightworker-seoul/tempo-coach-app/releases/latest/download/tempo-coach.apk)** (안드로이드 8 이상)

## 설치

1. 폰에서 위 링크를 눌러 APK를 받아요.
2. 받은 파일을 열면 "출처를 알 수 없는 앱" 허용을 물어봐요. 이번 한 번만 허용하고 설치해요.
3. 처음 시작할 때 알림 권한을 허용해 주세요. 화면을 꺼도 세션이 계속되려면 필요해요.
4. 음성이 안 나오면 설정 → 텍스트 음성 변환에서 한국어 음성을 설치하세요.

## 세션 구성 (총 33분 20초, 운동시간 30분)

- 10종목 × 6회 × 3세트, 세트마다 45초 운동 + 15초 휴식
- 종목 사이 기구 이동 20초: 운동 이름, 자세 한 줄, 템포를 읽어 줘요
- 1회 = 템포 동작 5초 + 시작 자세 2.5초
  - 1-0-4: 빠르게 들고(삑) 4초 동안 내리기(하나·둘·셋·넷)
  - 4-0-1: 4초 동안 내리고 빠르게 올리기 (펜듈럼 스쿼트, 인클라인 덤벨 프레스, 디클라인 트라이셉스 익스텐션)
- 세트 직전 "삼, 이, 일, 시작"

|---|---|---|
| 1 | 데드리프트 | 1-0-4 |

## 음악

- **유튜브·유튜브 뮤직·스포티파이에서 플레이리스트를 틀어 두세요.** 안내가 나올 땐 음악이
  작아지고, 기구 이동 20초와 일시정지 때는 멈췄다가 세트가 시작되면 다시 나와요.
  화면을 끈 채 쓰려면 백그라운드 재생이 되는 앱(유튜브 프리미엄, 스포티파이 등)이 필요해요.
- 또는 앱 위쪽 **음악 고르기**로 폰에 있는 음악 파일을 고르면, 앱이 직접 틀고 같은 방식으로 조절해요.

## 이어폰 버튼

- 한 번: 일시정지 / 재개 (재개하면 3초 전부터)
- 두 번: 다음 구간으로 넘기기

알림창에서도 일시정지·다음·종료를 누를 수 있어요.

## 주의

있는 만큼만 드세요.
